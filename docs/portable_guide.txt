사내 업무 캘린더 & 투두 매니저 v1.3.0 - 무설치 실행본 사용 안내
===============================================================

■ 필요 환경
  - Windows 10 / 11 (64비트). 설치 과정과 Python이 필요 없습니다.
  - 인터넷 연결이 필요 없고, 외부로 어떤 통신도 하지 않습니다.

■ 처음 실행
  1. 압축을 풀어 나온 TodoCalendar_Portable 폴더를 통째로 원하는 곳에 둡니다.
     (권장: C:\TodoCalendar 처럼 짧은 경로. 바탕화면도 괜찮습니다.)
  2. 폴더 안의 TodoCalendar_Portable.exe 를 실행합니다.
  3. "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누릅니다.
     백신(V3 등)이 막으면 보안부서에 예외(허용) 등록을 요청하세요.
     (서명되지 않은 프로그램이라 생기는 경고입니다.)

■ EzQ 쪽지 자동 수집 (쪽지 창을 열기만 하면 등록)
  1. 화면 오른쪽 위 [EzQ 쪽지 수집]이 체크되어 있는지 확인합니다. (기본: 켜짐)
  2. EzQ로 쪽지가 오면 받은쪽지 창을 엽니다.
  3. 3초쯤 뒤 화면 왼쪽 위에 "신규 문서/메시지 1건 자동 감지"가 표시되고,
     쪽지 속 기한(예: "내일 오전까지", "금일까지")이 실제 날짜·시각으로 바뀌어 일정에 등록됩니다.
  - "네, 알겠습니다" 같은 답장과 단순 인사말, 단순 공지, 결재·메일·통합 알림 쪽지는 등록되지 않습니다.
  - 같은 쪽지는 창을 다시 열거나 프로그램을 다시 켜도 한 번만 등록됩니다. (지운 업무도 다시 생기지 않음)

■ 확인 필요 / 업무 아님 / 제외된 쪽지·문서 (v1.3.0)
  - 요청은 있지만 기한·첨부·공문이 없는 쪽지("관련 내용 공유해주세요~" 등)는
    [❔ 확인 필요 N건]에 모입니다. 캘린더·알림·브리핑에는 나오지 않습니다.
    버튼을 눌러 [업무 맞음](캘린더로) 또는 [업무 아님]을 고르세요.
  - 잘못 등록된 쪽지 업무는 우클릭 → [🚫 업무 아님]. 확인 창 없이 지워지고,
    10초 동안 왼쪽 위 [↩ 되돌리기]로 되살릴 수 있습니다.
  - [🧾 제외된 쪽지·문서]: 업무가 아니라고 판단한 쪽지·문서를 판정 근거와 함께 봅니다.
    놓친 업무가 있으면 골라서 [업무로 등록]을 누르세요.
    '전체 판정 기록'에서는 실수로 삭제한 쪽지 업무도 되살릴 수 있습니다.
  - 업무관리시스템 문서 본문도 쪽지와 같은 점수표로 판정합니다. 배부받은 문서(결재시행 목록)는
    판정하지 않고 기한만 확정합니다. 애매한 문서는 [❔ 확인 필요]로, 제외된 문서는
    [🧾 제외된 쪽지·문서]에서 [업무로 등록]할 수 있습니다.
  - 업무를 고르면 상세 화면에 "판정: 등록 9점 — 부탁 표현 +3, …"처럼 판단 근거가 나옵니다.
  - 받은 시각은 쪽지 창을 처음 연 시각으로 계산합니다. 쪽지는 오는 대로 열어 주세요.
  - 창을 열지 않은 쪽지는 수집되지 않습니다. 쪽지 내용은 화면에서 읽기만 하고 메신저는 건드리지 않습니다.
  - 보낸 사람은 본문 끝에 "발신자 :" 줄이 있을 때만 표시됩니다.
  - 끄려면 [EzQ 쪽지 수집] 체크를 풉니다.

■ 기간 업무
  - 업무 추가·편집 창의 [시작일 (기간일 때)]에 날짜를 넣으면 시작일~마감일이 한 업무가 됩니다.
    (마감일 = 끝 날짜. 시작일을 비우면 예전처럼 마감일만 있는 업무입니다.)
  - 달력에는 시작~끝 모든 칸에 표시되고, 이어지는 칸은 "▸ "가 붙습니다.
    끌어다 놓으면 기간 전체가 같은 길이로 옮겨집니다.
  - 날짜를 누르면 그 날이 기간 안에 있는 업무도 목록에 나옵니다.
    목록에는 "MM/DD~MM/DD", 상세에는 "기간: …"으로 보입니다.
  - 반복 + 기간: 완료하거나 끝나는 날이 지나면 같은 길이의 다음 기간이 활성화됩니다.
    지난 기간을 완료하지 않았으면 기한경과로 남고, 지운 다음 기간은 다시 생기지 않습니다.
    프로그램을 켤 때와 하루 한 번 확인합니다.
  - 쪽지·문서·폴더/클립보드·빠른 입력에서 "11/10 ~ 11/14", "11.10.~11.14.", "11/10~14"처럼
    "~"로 쓴 기간은 자동으로 시작일·마감일로 읽습니다. "3~4명", "~3쪽" 같은 숫자 범위는 기간이 아닙니다.
  - 알리기만 하는 통보형 공문("안내해드립니다", "숙지하시기 바랍니다" 등)과 요청이 없는 문서는
    제외로 판정하며, [🧾 제외된 쪽지·문서]에서 [업무로 등록]할 수 있습니다.
    이 판정은 업무관리시스템 문서 창·쪽지에만 적용되며, 폴더·클립보드로 넣은 PDF/txt는
    예전 판정 그대로입니다(기한·기간 읽기만 개선).

■ 업무관리시스템 배부 문서 자동 등록 (v1.4.0)
  1. 화면 오른쪽 위 [업무관리 문서 수집]이 체크되어 있는지 확인합니다. (기본: 켜짐)
  2. 업무관리시스템 [전자문서 > 결재 > 결재시행] 목록 화면을 열어 둡니다.
  3. 부서장이 나를 업무담당자로 배부하면, 목록에 나타난 문서가 3초쯤 뒤 업무로 등록됩니다.
     목록에는 처리기한이 없어 기한은 3영업일 뒤로 임시로 잡히고 '·기한추정'으로 표시됩니다.
  4. 그 문서를 열면 본문의 회신기한(예: '26.11.7(금))으로 기한이 바뀝니다. 업무는 1건 그대로입니다.
  - 처리구분이 '업무관리자'인 문서는 [❔ 확인 필요]에 모입니다. [업무 맞음] 또는 [업무 아님]을 고르세요.
    [업무 아님]으로 지운 문서는 목록에 다시 나오거나 문서를 열어도 다시 등록되지 않습니다.
  - 같은 일을 동료 쪽지로 먼저 받았으면 새로 만들지 않고 그 쪽지 업무에 배부 출처를 붙입니다.
  - 목록 화면은 읽기만 합니다. 문서를 열거나 결재하지 않습니다.

■ 파일로 업무 올리기 (감시 폴더)
  1. 화면 왼쪽 위 [⚙ 감시 폴더 설정] → [＋ 폴더 추가]
  2. 메신저 쪽지를 저장하는 폴더, 공문 PDF를 내려받는 폴더를 추가합니다.
     - 받을 파일 '쪽지·공문만' : 쪽지 저장 파일(발신자-날짜_시각.txt)과 공문 PDF만 처리
     - 가져올 범위 '오늘부터 저장된 파일' : 예전 파일이 한꺼번에 등록되지 않음
       (이미 받아 둔 파일까지 올리려면 '최근 7일' / '최근 30일' / '전체 파일')
  3. [저장하고 바로 확인]을 누르면 결과 목록이 나오고,
     이후에는 파일을 저장하면 15초 안에 일정에 자동 등록됩니다.

■ 이미 받아 둔 파일을 한 번에 올리기
  - [📄 파일 불러오기]에서 Ctrl·Shift 클릭 또는 Ctrl+A로 여러 파일을 고릅니다.
  - 파일마다 결과(새 업무 등록 / 기존 업무 갱신 / 업무 아님 / 제외)가 목록으로 나옵니다.
  - 프로그램 폴더 안 scan_inbox 폴더에 파일을 넣어도 자동으로 등록됩니다.

■ 여러 업무 한 번에 지우기
  - 오른쪽 업무 목록이나 일정 목록에서 Ctrl·Shift 클릭(또는 Shift+↑↓, Ctrl+A)으로
    여러 건을 고르고 [🗑️ 삭제] 버튼이나 Delete 키를 누릅니다.
  - 확인 창에 지울 건수와 제목이 나옵니다. 삭제한 업무는 되돌릴 수 없습니다.

■ 키보드 단축키 (F1을 누르면 화면에서도 볼 수 있습니다)
  [어디서나]
    Ctrl+N 새 업무          Ctrl+L 빠른 입력 칸으로
    Ctrl+1 오른쪽 업무 목록으로   Ctrl+2 일정 목록 보기로
    Alt+← / Alt+→ 이전 달 / 다음 달   Ctrl+T 오늘
    F5 폴더 스캔            Ctrl+Shift+V 클립보드 스캔
  [업무 목록에서]
    ↑ ↓ 이동   Shift+↑↓ · Ctrl+A 여러 건 선택   Esc 선택 해제
    Enter 편집   Space 완료/미완료 전환   Delete 고른 업무 삭제
  [업무 편집 창에서]
    Ctrl+Enter 저장   Esc 닫기(저장 안 함)
  - Delete·Enter·Space는 업무 목록에 커서가 있을 때만 동작합니다.
    빠른 입력 칸에서 Delete를 눌러도 업무는 지워지지 않습니다.

■ 인식이 이상할 때
  - 필터 줄의 [🔎 점검]으로 파일을 고르면 등록하지 않고 인식 결과만 보여줍니다.
  - 글자가 깨지거나 기한이 틀리면 [공유용 요약 복사] 내용을 전달해 주세요.
    (파일 이름·제목·본문은 빠지고 구조 정보만 들어 있습니다.)
  - 읽을 수 없는 파일: 스캔 이미지 PDF, 보안 설정(암호화) PDF, DRM으로 잠긴 파일

■ 이전 버전에서 바꾸기 (등록된 업무 유지)
  1. 기존 폴더의 todo_data.db 와 config.json 을 따로 복사해 둡니다.
  2. 새 TodoCalendar_Portable 폴더로 바꾼 뒤 두 파일을 다시 넣습니다.
  3. 예전 config.json 에는 예전 버전 번호(1.1.1, 1.2.0 등)가 적혀 있어 창 제목에 그대로 나옵니다.
     메모장으로 "version": "1.3.0" 으로 고치면 됩니다. (쪽지 수집은 고치지 않아도 켜져 있음)
  4. 예전 버전에서 제목 앞에 "[확인 필요]"가 붙어 등록된 쪽지 업무는
     처음 실행할 때 자동으로 [❔ 확인 필요]로 옮겨집니다.

■ 데이터 위치와 백업
  - 모든 데이터는 이 폴더 안에만 저장됩니다.
      todo_data.db  : 등록된 업무 (처음 실행할 때 생김)
      config.json   : 설정 (감시 폴더, EzQ 쪽지 수집 등)
      scan_inbox    : 기본 감시 폴더
  - 다른 PC로 옮기거나 백업할 때는 폴더를 통째로 복사하세요.
  - 프로그램을 지우려면 폴더를 삭제하면 됩니다.
    ([출근 시 자동실행]을 켰다면 먼저 체크를 끄고 지우세요.)

■ 알려진 한계
  - 쪽지 판단은 규칙으로 하므로 틀릴 수 있습니다. 잘못 등록되면 [업무 아님],
    놓쳤으면 [🧾 제외된 쪽지·문서]에서 [업무로 등록]을 쓰세요.
  - 저장 파일(txt)로 넣은 쪽지와 공문 PDF는 아직 예전 방식(업무 단어 하나만 있어도 등록)으로
    판단합니다. 안내·알림성 공문도 등록될 수 있으니 필요 없으면 삭제하세요.
  - 여러 명에게 보낸 쪽지에서 내 몫인지는 구분하지 않습니다.
  - 배부 문서는 결재시행 목록 화면을 열어 둔 동안에만 등록됩니다. 목록 첫 화면에 보이는 문서만 읽습니다.
  - 배부 문서를 결재(처리)해 목록에서 사라져도 업무는 자동으로 완료되지 않습니다. 직접 완료 처리하세요.
  - 기한 변경·취소 쪽지는 기존 업무에 자동 반영되지 않습니다.
  - 미완료 반복 기간 업무는 주마다 기한경과 1건씩 쌓일 수 있습니다.
  - 메신저가 업데이트된 뒤 쪽지가 수집되지 않으면 알려 주세요.
    (쪽지 창 이름이 바뀐 경우 config.json 의 ezq_window_class 로 맞출 수 있습니다.)
